FAQ

Do I need an API key?

No. Core analysis, templates, and PDF generation work with AI_DISABLED=true. API keys are optional for future AI enhancements only.

Is my code executed?

No. We never execute uploaded files. Analysis is static (regex + manifest parsing). Live preview is opt-in, sandboxed, and gracefully falls back to static.

Will it leak secrets into the PDF?

Never. Secrets are redacted with *** before rendering. The PDF only shows “Hard-coded API key detected at config.js:12” — not the value.

What ZIPs are supported?

Any ZIP up to 50 MB, 10k files, 10 MB/file. We block traversal, bombs, symlinks. Try for a demo.
